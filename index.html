9월 → 10월 체납세대 흐름

전체 기준 (필터와 무관) · 여현서 A05 지표계산 전월대비

wise에서 내려받은 원천 Excel 9종을 계약번호로 이어 계약 1건을 1행으로 만든 단계입니다. 뒤 단계(분류, 보고)가 모두 이 파일을 이어받습니다.

통합데이터의 조치 진행 열 · 오른쪽 숫자 = 완료 세대 · 연한 색 = 대상이지만 아직 안 함

파일별 매핑 결과

현재 단계 분포

계약별로 가장 뒤까지 진행한 조치 단계

통합 파일을 받아 체납기간과 보증금잠식률로 대상자를 나누고, 꾸준히 납부 중인 세대는 보류로 빼고, 세대별로 다음에 할 조치를 정하는 단계입니다.

최종분류별 세대

처리과정 뒤 단계부터 · 색은 관리 상태

판단 기준값

팀원/신미림/체납관리_기준값.json · 숫자만 바꾸면 분류도구가 바뀐 기준으로 분류

조치 순서: 1차 납부최고 → 2차 납부최고 → 가옥명도최고 → 분과심의 → 소송통고 1차 → 제소의뢰 → 소송통고 2차 → 본안소송 → 판결. 앞 단계를 안 했으면 가장 앞의 안 한 단계를 안내합니다.

체납기간별

단기 3~5개월 · 중기 6~11개월 · 장기 12개월 이상

익월 재검토 세대

분과심의 보류 · 소송유예 · 생활안정지원 → 다음 달에 같은 기준으로 다시 검토

분류 결과를 받아 월 결산 지표를 계산하고 보고서 초안을 만드는 단계입니다. 아래 수치는 9월 결과에 10월 변동을 가상으로 적용한 테스트용 값입니다.

웹에 공개되는 페이지라 계약자 이름·주민번호·주소·연락처는 싣지 않았고 계약번호는 가운데를 가렸습니다.

새 체납 데이터 Excel을 넣으면 이 페이지의 모든 화면(전체 현황 · 세대 목록 · 각 단계)이 그 데이터로 바뀝니다. 파일은 이 브라우저 안에서만 읽고 어디에도 보내지 않습니다. 페이지를 새로고침하면 기본(가상) 데이터로 돌아갑니다.

① 통합 실행 결과 2개 넣기 권장

팀원/취합/체납관리_통합실행/체납관리_실행.bat이 결과/<연월>/에 만든 두 파일

  • 체납관리_통합데이터_YYYYMM.xlsx (A01 · 김태경)
  • 체납관리_분류결과_YYYYMM.xlsx (A02~A04 · 신미림)
두 파일을 여기에 끌어다 놓거나 눌러서 선택
분류도구(HTML·Python)가 만든 분류결과 Excel도 됩니다

② 원본 Excel 9개 넣기

wise에서 받은 체납집계표 · 납부최고서 1·2차 · 가옥명도최고 · 분과심의 · 소송통고 1·2차 · 제소자 · 소송정보. 이 페이지가 통합(A01)과 분류(A02~A04)까지 합니다 — 분류도구 ver.6과 같은 규칙

판단 기준값은 「② 대상자 분류」 화면의 값 사용 · 체납관리_기준값.json을 같이 넣으면 그 값 사용
