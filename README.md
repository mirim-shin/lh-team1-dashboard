# 1팀 체납관리 홈 (LH AI Workflow 워크숍)

전세임대 체납관리 AI Agent PoC의 결과를 한 화면에 모은 대시보드입니다.

- 페이지: https://mirim-shin.github.io/lh-team1-dashboard/
- 흐름: A01 데이터 통합(김태경) → A02~A04 대상자 분류(신미림) → A05 월 결산 보고(여현서)
- 도표의 칸·막대 이름·범례·숫자 카드를 누르면 해당 조건의 세대 목록으로 이동합니다.
- 세대 목록은 [요약 | 상세]로 바꿔 볼 수 있고, 상세에서는 세대별 9단계 조치 진행(납부최고 1차 ~ 판결)을 점으로 봅니다.

## 데이터

- **모두 테스트용 가상 데이터**이며 실제 체납 실적이 아닙니다.
- 이름·주민번호·주소·연락처는 넣지 않았고, 계약번호는 앞 4자리와 끝 3자리만 보이게 가렸습니다.

## 출처

팀 작업 저장소(비공개)의 `dashboard/index_ver.4.html`을 그대로 옮긴 것입니다. 원본이 바뀌면 이 저장소의 `index.html`을 새 파일로 바꿔 올립니다.
